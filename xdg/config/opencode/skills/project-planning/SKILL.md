# Project Planning

Translate outcomes into measurable acceptance criteria. Identify dependencies, owners, milestones and major risks. Make the first executable step small and reversible. For small requests avoid heavyweight task tracking. Review the plan after new evidence appears; keep status claims tied to verified outputs.
